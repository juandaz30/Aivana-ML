# AIVANA
## Información del Proyecto
Sistema interactivo para la generación de modelos de ML sin programación
¡Bienvenido a AIVANA! Este proyecto busca democratizar el Machine Learning permitiendo que estudiantes interesados en el área puedan gestionar e interactuar con modelos ML a través de una interfaz web intuitiva, sin tocar una sola línea de código.

## Instalación y Configuración:
1. Clona y accede al repositorio:
   ```bash
   git clone https://github.com/juandaz30/Aivana-ML
   cd Aivana-ML
   ```

2. Instala las dependencias (asegúrate de tener python instalado):
   ```bash
   pip install flask pandas numpy joblib
   ```
3. Ejecuta el servidor de la aplicación:
   ```bash
   pyhton app.py
   ```
4. Ingresa a la URL local desde el navegador: http://127.0.0.1:5000/

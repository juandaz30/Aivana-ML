# AIVANA 

## Información del Proyecto

Sistema interactivo para la generación de modelos de ML sin programación ¡Bienvenido a AIVANA! Este proyecto busca democratizar el Machine Learning permitiendo que estudiantes interesados en el área puedan gestionar e interactuar con modelos ML a través de una interfaz web intuitiva, sin tocar una sola línea de código. 

## Instalación y Configuración: 

1. Descarga GIT y Python si aún no los tienes accediendo a los siguientes enlaces:
* [ ] **Git**: [Descargar aquí](https://github.com/git-for-windows/git/releases/download/v2.53.0.windows.1/Git-2.53.0-64-bit.exe)

Una vez descargado, ejecuta el archivo resultante y sigue las preconfiguraciones de instalación por defecto.

* [ ] **Python**: [Descargar aquí](https://www.python.org/ftp/python/3.13.12/python-3.13.12-amd64.exe).

Una vez descargado, ejecuta el archivo resultante y selecciona la opción 'Install Now'

2. Abre una terminal de comandos para configurar la instalación del proyecto en los siguientes pasos

3. Instala las dependencias (asegúrate de tener python instalado):
````bash
   py -m pip install flask pandas numpy joblib
````

5. Clona y accede al repositorio:
````bash
   git clone https://github.com/juandaz30/Aivana-ML
   cd Aivana-ML/backend
````

6. Ejecuta el servidor de la aplicación:
````bash
   py app.py
````

8. Ingresa a la URL local desde el navegador:
* [ ] **Aivana**: [Ingresa Aquí](http://127.0.0.1:5000/)

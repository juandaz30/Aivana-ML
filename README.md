# Nombre del Proyecto
Sistema interactivo para la generación de modelos de ML sin programación
¡Bienvenido a AIVANA! Este proyecto busca democratizar el Machine Learning permitiendo que estudiantes interesados en el área puedan generar modelos potentes a través de una interfaz de Flask, sin tocar una sola línea de código.

# Instalación y Configuración
1. git clone https://github.com/juandaz30/Aivana-ML
    cd 
2. Instala las dependencias (asegúrate de tener pyhton instalado): pip install flask pandas numpy joblib
3. Ejecuta la aplicación: python app.py y abre la URL local
